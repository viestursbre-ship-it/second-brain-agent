# 🧠 Second Brain Agent

> Proactive AI assistant that learns your tone of voice, tracks document habits, and generates structured templates from historical data.

---

## ⚡ Features
* **Drop Zone Ingestion:** Scan past proposals, notes, and documents (`.txt`, `.md`, `.docx`, `.pdf`).
* **Style DNA Synthesis:** Automatically extracts Tone of Voice, structure patterns, and recurring formatting rules.
* **Smart Draft Generator:** Produces new documents precisely matching the user's authentic style.

---

## 🚀 Quickstart

1. **Install dependencies:**
   \`\`\`bash
   pip install -r requirements.txt
   \`\`\`

2. **Add context documents:**
   * Place sample files inside the `./dropzone` folder.

3. **Set API Key & Run:**
   \`\`\`bash
   export GEMINI_API_KEY="your_api_key_here"
   python main.py
   \`\`\`
